Screen flow — every screen & state, as static mockups
These are static HTML snapshots for reviewing the flow, built with mock data from the real CSS/markup in index.html / js/render.js. They aren't wired up to Firebase or any app logic — nothing here is clickable in a functional sense. Not part of the shipped app.

Screen 1

2. Landing

Landing — joiner

3. Lobby
Screen 3a
Lobby — host
Sees the "Zapocni igru" start button once ≥2 players joined.
Screen 3b
Lobby — guest
Waits on the host to start; no start button.

Screen 6
Round end — announce
All-players row + winner banner over the final board; here a regular win, winner's final meld highlighted orange.

Round end — scores
