Interactive joker-partition test

Play each scenario as if you were the player: click cards in your hand to select them, then click "Izloži izabrano" exactly like in the real game. If the selection can be split into melds in more than one way, you'll get the same "Kako da podelim izabrane karte?" picker the real game now shows - pick an option and watch the table update. Reset replays the same hand from scratch.
